# Тесты для задачи 3 варианта 1
## Сортировка строк матрицы по убыванию наибольших элементов

## Входные данные
Первая строка: количество строк
Вторая строка: количество столбцов 
Далее: количество строк по количеству столбцов целых чисел

## Выходные данные
Матрица после сортировки строк

## Позитивные тесты:
- 01 - разные максимумы
- 02 - максимумы уже по убыванию
- 03 - матрица 2x2
- 04 - одна строка
- 05 - матрица с отрицательными числами
- 06 - матрица с одинаковыми максимумами

## Негативные тесты:
- 01 - количество строк больше максимума
- 02 - количество столбцов больше максимума
- 03 - количество строк равно 0
- 04 - количество столбцов равно 0
- 05 - отрицательное количество строк
- 06 - отрицательное количество столбцов
- 07 - нечисловой ввод строк
- 08 - нечисловой ввод столбцов
- 09 - нечисловой ввод элемента
