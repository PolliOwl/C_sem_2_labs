# Тесты для задачи 6 варианта 5

## Входные данные
8 чисел - координаты двух отрезков

## Выходные данные
1 - отрезки пересекаются, 0 - не пересекаются

## Позитивные тесты:
- 01 - отрезки пересекаются - диагонали
- 02 - отрезки пересекаются - вертикаль и горизонталь
- 03 - отрезки не пересекаются
- 04 - граничный тест
- 05 - отрезки не пересекаются - они параллельны

## Негативные тесты:
- 01 - координаты точек 1ого отрезка совпадают
- 02 - вместо чисел буквы в 1ом отрезке
- 03 - вместо чисел буквы в 2ом отрезке
- 04 - координаты точек 2ого отрезка совпадают
