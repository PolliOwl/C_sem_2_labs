# Тесты для задачи 1 варианта 3
## Проверка строк матрицы на монотонность

## Входные данные
Первая строка: количество строк
Вторая строка: количество столбцов 
Далее: количество строк по количеству столбцов целых чисел

## Выходные данные
Результирующий массив из количества строк элементов 
(1 - строка монотонна, 0 - иначе)

## Позитивные тесты:
- 01 - все строки монотонны возрастающие
- 02 - все строки монотонны убывающие
- 03 - две строка монотонны, одна нет
- 04 - разные случаи монотонности
- 05 - проверка с двумя столбцами
- 06 - одни и те же числа в строке

## Негативные тесты:
- 01 - количество строк больше максимального
- 02 - количество столбцов больше максимального
- 03 - количество строк равно 0
- 04 - количество столбцов равно 0
- 05 - отрицательное количество строк
- 06 - отрицательное количество столбцов
- 07 - нечисловой ввод количества строк
- 08 - нечисловой ввод количества столбцов
- 09 - нечисловой ввод элемента матрицы
