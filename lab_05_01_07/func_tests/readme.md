# Тесты для задачи 1 варианта 7

## Входные данные
Целые числа, признак окончания ввода - любой инвалидный ввод

## Выходные данные
Одно число - количество локальных максимумов

## Позитивные тесты:
- 01 - обычная последовательность с двумя локальными максимумами
- 02 - последовательность с тремя локальными максимумами
- 03 - возрастающая последовательность, нет локальных максимумов
- 04 - все числа равны, нет локальных максимумов
- 05 - отрицательные числа

## Негативные тесты:
- 01 - пустой ввод (нет данных)
- 02 - только два числа
- 03 - нечисловой ввод
