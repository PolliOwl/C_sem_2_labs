# Тесты для задачи 2 варианта 3
## Удаление столбцов, содержащих числа с заданной цифрой

## Входные данные
Первая строка: количество строк
Вторая строка: количество столбцов 
Далее: количество строк по количеству столбцов целых чисел
Последняя строка: цифра (0-9)

## Выходные данные
Матрица без столбцов, содержащих числа с цифрой

## Позитивные тесты:
- 01 - удаление одного столбца посередине
- 02 - удаление нескольких столбцов
- 03 - удаление первого столбца
- 04 - ни один столбец не удаляется
- 05 - удаление всех столбцов кроме одного
- 06 - отрицательные числа с цифрой

## Негативные тесты:
- 01 - количество строк больше максимума
- 02 - количество столбцов больше максимума
- 03 - количество строк равно 0
- 04 - количество столбцов равно 0
- 05 - отрицательное количество строк
- 06 - отрицательное количество столбцов
- 07 - нечисловой ввод строк
- 08 - нечисловой ввод столбцов
- 09 - нечисловой ввод элемента
- 10 - цифра меньше 0
- 11 - цифра больше 9
- 12 - нечисловой ввод цифры
