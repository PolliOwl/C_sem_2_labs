# Тесты для задачи 6 варианта 3
## Заполнение квадратной матрицы по спирали против часовой стрелки

## Входные данные
Первая строка: размер квадратной матрицы

## Выходные данные
Матрица, заполненная числами от 1 по спирали против часовой стрелки

## Позитивные тесты:
- 01 - матрица 1x1
- 02 - матрица 2x2
- 03 - матрица 3x3
- 04 - матрица 5x5

## Негативные тесты:
- 01 - количество строк больше максимума
- 02 - количество столбцов больше максимума
- 03 - количество строк равно 0
- 04 - количество столбцов равно 0
- 05 - отрицательное количество строк
- 06 - отрицательное количество столбцов
- 07 - нечисловой ввод строк
- 08 - нечисловой ввод столбцов
- 09 - нечисловой ввод элемента
