# Тесты для задачи 3 варианта 0

## Входные данные
Строка до 256 символов

## Выходные данные
Результат после фразы "Result: " (если не пустой)

## Позитивные тесты:
- 01 - обычная строка
- 02 - одно слово с повторяющимеся буквами, другое нет
- 03 - пробелы между словами и до них
- 04 - строка с 4 словами

## Негативные тесты:
- 01 - пустая строка
- 02 - только разделители
- 03 - строка длиннее 256 символов
- 04 - слово длиннее 16 символов
