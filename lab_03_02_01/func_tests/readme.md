# Тесты для задачи 2 варианта 1
## Удаление строки и столбца, на пересечении которых находится элемент с минимальной суммой цифр

## Входные данные
Первая строка: количество строк
Вторая строка: количество столбцов 
Далее: количество строк по количеству столбцов целых чисел

## Выходные данные
Матрица после удаления строки и столбца

## Позитивные тесты:
- 01 - матрица 3x3, минимум в центре
- 02 - матрица 3x3, минимум в левом верхнем углу
- 03 - матрица 2x2
- 04 - матрица 3x3 с отрицательными числами
- 05 - матрица 3x3 с двузначными числами
- 06 - матрица 2x3 с отрицательными числами

## Негативные тесты:
- 01 - количество строк больше максимума
- 02 - количество столбцов больше максимума
- 03 - количество строк равно 0
- 04 - количество столбцов равно 0
- 05 - отрицательное количество строк
- 06 - отрицательное количество столбцов
- 07 - нечисловой ввод строк
- 08 - нечисловой ввод столбцов
- 09 - нечисловой ввод элемента
