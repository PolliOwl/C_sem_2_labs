# Тесты для задачи 4 варианта 1

## Входные данные
Аргументы командной строки

## Выходные данные
Фамилия, имя, оценки (в одну строку через пробел)

## Позитивные тесты:
- 01 - сортировка студентов по фамилии и имени (sb)
- 02 - фильтр студентов по подстроке "Iv" (fb)
- 03 - удаление студентов со средним баллом ниже среднего (db)

## Негативные тесты:
- 01 - импорт несуществующего файла
- 02 - сортировка несуществующего файла
- 03 - фильтр несуществующего файла
- 04 - удаление из несуществующего файла
- 05 - неизвестный ключ
