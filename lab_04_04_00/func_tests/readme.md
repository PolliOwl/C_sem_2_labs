# Тесты для задачи 4 варианта 0

## Входные данные
Строка до 256 символов

## Выходные данные
YES или NO - является ли строка IP-адресом или нет

## Позитивные тесты:
- 01 - обычный адрес
- 02 - с пробелами до и после строки
- 03 - с табуляцией до и после строки
- 04 - максимально возможный IP-адрес

## Негативные тесты:
- 01 - пустая строка
