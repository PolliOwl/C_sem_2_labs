# Тесты для задачи 2 варианта 0

## Входные данные
Строка до 256 символов

## Выходные данные
Пары "слово количество" после фразы "Result:"

## Позитивные тесты:
- 01 - обычная строка с повторяющимися словами
- 02 - все слова одинаковые
- 03 - разные разделители
- 04 - пробелы в начале и конце перед словом

## Негативные тесты:
- 01 - пустая строка
- 02 - только разделители без слов
